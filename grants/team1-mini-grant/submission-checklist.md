# Team1 application submission checklist

**Current status: preparation only. No application submitted.**

## Content readiness

- [ ] Applicant identity, contact details, team roles, and experience are accurate.
- [ ] Proposed grant amount, budget, milestone scope, and timeline have applicant approval.
- [ ] Project and evidence links are accessible to the intended reviewers.
- [ ] Actual form fields and length/file limits have been checked after sign-in.
- [ ] Application distinguishes existing mobile code from the unbuilt AdWeb3 platform.
- [ ] No unverified user counts, revenue, advertisers, partnerships, funding, deployments, or store approvals are claimed.
- [ ] Android/Google Play reward-policy requirements and testnet-only funded scope are disclosed consistently.
- [ ] Grant spending is separate from advertiser funding and the 30/60/10 operating model.
- [ ] Budget rows and milestones reconcile to the same requested amount.
- [ ] Open-source/publication promises match the applicant's decision and actual grant terms.
- [ ] Any private source, screenshots, quotes, or organizational names are approved for sharing.

## Official application flow

1. Open the application from [Team1's official grant page](https://www.team1.network/grants), following its link to [Builder Hub](https://build.avax.network/grants/team1-mini-grants/apply).
2. Sign in using the applicant's account. Read the current account and program terms.
3. Review the stated sharing consent with Team1 and any project visibility settings.
4. Choose/create the correct project, confirm applicant details, and add only actual teammates.
5. Map the prepared answers to the exact form; validate all links, uploads, amounts, and commitments.
6. Have the applicant review the complete populated application before the final submission action.
7. Record the confirmation/reference and submitted version; save any program communications and reporting obligations.

This task authorizes local preparation only. Submission, account creation, accepting terms, publishing source, contacting Team1, or uploading applicant material has not been performed or assumed authorized.
