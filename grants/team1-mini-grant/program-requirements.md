## Recommended supporting materials

Prepare a concise project brief, evidence links, founder biography, use-of-funds budget, measurable milestone proposal, and a short demo. These are useful application preparation materials, not claimed mandatory uploads. Create a pitch deck or PDF only if the form/reviewer requests it or the applicant elects to include one.
